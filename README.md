# GLD Univers Market — versioni 1.0

A starter Expo/React Native app for Android + iPhone.

## Çfarë përfshin
- Home me ofertat
- Kategori produktesh
- Kërkim dhe filtrim
- Shportë dhe total
- Porosi (demo)
- Profil klienti (demo)
- Strukturë gati për integrim me backend, pagesa elektronike dhe dërgesa

## Për ta hapur
1. Instalo Node.js dhe Expo.
2. Në këtë dosje ekzekuto `npm install`.
3. Ekzekuto `npx expo start`.
4. Testoje me Expo Go ose emulator/simulator.

**Shënim:** Pagesat elektronike nuk janë lidhur ende me bankën/gateway-in real. Duhet të përdoren kredencialet dhe API-t e ofruesit të pagesave të GLD Univers Market.
